* Fix Consult Ripgrep
In windows, it looks like executing ripgrep in quick succession causes the process to suspend, freezing emacs as a result.
This implements a debounce and throttle to allow the previous ripgrep process to terminate before the next one starts.
#+BEGIN_SRC elisp
(after! consult
  (when IS-WINDOWS
    (setq consult-async-input-debounce 0.3
          consult-async-input-throttle 0.5
          consult-async-refresh-delay 0.2)))
#+END_SRC

* Magit
https://mbork.pl/2022-11-19_Streamlining_my_workflow_with_Magit_and_BitBucket
#+BEGIN_SRC elisp
(defun magit-open-pull-request-pr ()
  "Open the pull request URL if applicable."
  (interactive)
  (save-excursion
    (set-buffer (magit-process-buffer t))
    (goto-char (point-max))
    (magit-section-backward)
    (when
        (search-backward-regexp "remote: \\(To create a merge\\|Create pull\\) request" nil t)
      (forward-line 1)
      (re-search-forward "remote: +" (line-end-position) t)
      (browse-url-at-point))))
#+END_SRC

* Angular
Make the server selection depend on whether the file belongs to an Angular project rather than on the major mode alone.
Angular projects almost always contain an angular.json at the project root. You can use that to detect Angular projects.
#+BEGIN_SRC elisp
(defun my/start-angular-eglot ()
  (when (and (derived-mode-p 'web-mode)
             (locate-dominating-file default-directory "angular.json"))
    (eglot-ensure)))

(add-hook 'web-mode-hook #'my/start-angular-eglot)
#+END_SRC
